# 60–90 second demo

## Setup

Launch on the iPhone 17 Pro simulator. Keep the status pills visible. If Rive export is complete, Renderer should say Rive; otherwise explicitly show that the same app is safely running its PNG fallback. Intelligence should say Apple Foundation Model when generation succeeds, or Personalized local with an explicit notice when Apple is unavailable or fails.

## Script

**0–10 seconds — Native character**

“Living Commish is a native SwiftUI character for Takes. He idles continuously, and the app shows which renderer and intelligence provider are actually active.”

**10–27 seconds — Fan-aware structured intelligence**

Enter **I’m going to the Whiteout game!!!**

“The app reads this as high-energy anticipation for a Penn State tradition, not generic news. Intent, sentiment, intensity, and fan memory drive an Electric mood and Foam Finger.”

Point to the personalized line and the Yes/Correct feedback controls. Correcting a reaction stores an on-device preference that changes similar future gestures and emotions.

**27–40 seconds — Appropriate response and idle return**

Tap **Lost Streak**.

“A loss produces an encouraging short response and Sad Shrug. One-shot animations return to idle automatically.”

**40–55 seconds — App-owned editable memory**

Open **Memory**.

“The model transcript is not memory. SwiftData owns a small visible profile on device. A normal Swift policy validates and deduplicates any proposed durable fact.”

Briefly show the explicit rating and learned-signal counts, individual delete, and Forget Everything, then dismiss.

**55–70 seconds — Resilient fallbacks**

Expand **Developer Controls** and tap **Demo Sequence**.

“The same controller drives idle, wave, point, foam finger, and sad shrug. If Rive is absent or invalid, PNG takes over. Apple generation retries once; if it still fails, the same semantic brief drives a personalized local response and the UI says so. Nothing needs a network or API key.”

**70–85 seconds — Apple integration and close**

“React with Commish is also an App Intent for Shortcuts, Siri, Spotlight, and eligible Action button setups. The product idea is simple: Living Commish privately understands a fan's Takes activity, responds in character, and always has a reliable local path.”

## Fast reset

Tap **Reset Demo** to restore seeded Penn State demo data, clear the visible event log, reset the model session, and return the character to idle.
